# **App Name**: FlightDataView

## Core Features:

- Data Fetch: Fetch the XLSX file from the provided URL (https://apps.dfwairport.com/flightexcel) using a serverless function.
- Data Parsing: Parse the XLSX file into a JSON format suitable for client-side processing using a tool.
- Data Filtering: Implement filtering based on user-selected criteria (e.g., flight number, destination) using a tool.
- Data Display: Display the filtered data in a tabular format with sortable columns. The table should be paginated for large datasets.

## Style Guidelines:

- Primary color: Use a calming blue (#3498db) for headers and main sections.
- Secondary color: Light gray (#f2f2f2) for background and card-like elements.
- Accent: Teal (#008080) for interactive elements like buttons and filter options.
- Clean and readable sans-serif fonts for data display.
- Use a responsive layout that adapts to different screen sizes.
- Simple and clear icons for filter options and column headers.

## Original User Request:
app to download xlsx file from "https://apps.dfwairport.com/flightexcel" and filter the data and show in a view.
